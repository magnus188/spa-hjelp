Hold lokket åpent

Når timeren er ferdig kan lokket lukkes. Dette sier ikke om vannet er klart for bading.

Rekkefølge ved justering: Alkalinitet → pH → MiniChlor → 20 min med pumpe 1 → Active Oxygen før bad. Mål på nytt mellom trinnene. Bare valgte produkter blir foreslått.

Juster verdier

Velg ønsket økning for alkalinitet, pH, klor og O₂. Veiviseren viser ett produkt om gangen.

Om rådene
